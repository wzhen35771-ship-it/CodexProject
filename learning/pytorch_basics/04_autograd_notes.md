# 第 4 课：自动求导与参数更新

## 本课概念

`requires_grad=True` 请求记录可求导运算。`backward()` 计算梯度并累加到叶子张量的 `.grad`。
对于 y=2x²+5x，x=3 时 y=33，导数 4x+5=17。
求导不会自动改变 x；SGD 更新为 x ← x − 学习率 × 梯度。
第二次求导前需要清除旧梯度。示例重新计算 y，因为默认 backward 后计算图会释放。
`torch.no_grad()` 内的更新不会被记录为新的求导过程。后续使用优化器完成更新。

## 怎么学

1. 先读概念，用纸笔预测示例输出。
2. 运行 [04_autograd_example.py](04_autograd_example.py)，逐行对照预测。
3. 关闭示例，完成 [04_autograd_exercise.py](04_autograd_exercise.py)。
4. 写下形状、实际输出、错误原因；能解释后进入下一课。

## 独立练习与验收

1. 独立手算 x=2 时 y=3x² 的值和导数，再用代码验证。
2. 用学习率 0.1 更新一次，打印求导前、求导后、更新后的参数。
3. 用两次独立前向试验不清零时的梯度累加，解释结果。

不以运行成功代替理解：至少独立完成全部任务，并解释每个关键操作。
