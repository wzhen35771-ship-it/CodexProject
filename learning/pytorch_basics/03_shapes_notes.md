# 第 3 课：形状变换与图像表示

## 本课概念

`reshape` 在元素总数不变时重新分组，`permute` 调换轴的位置。
图片常用 HWC：高、宽、通道；PyTorch 卷积常用 NCHW：批次、通道、高、宽。
HWC → CHW 应使用 `permute(2, 0, 1)`，不能只靠 reshape 来交换通道轴。
`unsqueeze(0)` 添加一个批次轴；`squeeze(0)` 只移除指定大小为 1 的轴。
真实 RGB 图片常见像素值为 0～255，通常先转换为浮点并缩放；本课仅用人工数值检查轴，不处理真实图片。

## 怎么学

1. 先读概念，用纸笔预测示例输出。
2. 运行 [03_shapes_example.py](03_shapes_example.py)，逐行对照预测。
3. 关闭示例，完成 [03_shapes_exercise.py](03_shapes_exercise.py)。
4. 写下形状、实际输出、错误原因；能解释后进入下一课。

## 独立练习与验收

1. 构造 [4, 5, 3] 人工图片，转为 [1, 3, 4, 5]。
2. 核对原图 [2, 1, 2] 与新张量的对应位置。
3. 解释 reshape 与 permute 的区别，以及 -1 的作用。

不以运行成功代替理解：至少独立完成全部任务，并解释每个关键操作。
