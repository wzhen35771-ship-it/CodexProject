# 第 7 课：完整训练循环

## 本课概念

每个 batch 按清零 → 前向 → 损失 → 反向 → 更新执行。
`model.train()` 设置训练模式；`optimizer.zero_grad()` 清除历史梯度；`backward()` 求导；`step()` 更新。
本课使用 SGD，学习率 0.1，12 条人工样本、batch_size=4，每轮更新 3 次。
每轮平均损失按 batch 损失乘样本数累加，再除以总样本数，避免最后一批较小时权重错误。
首先验证小数据能否拟合。训练准确率高只证明见过的样本拟合良好，不能据此宣称泛化能力。
运行本课不保存文件；下一课学习独立数据评估与保存加载。

## 怎么学

1. 先读概念，用纸笔预测示例输出。
2. 运行 [07_training_example.py](07_training_example.py)，逐行对照预测。
3. 关闭示例，完成 [07_training_exercise.py](07_training_exercise.py)。
4. 写下形状、实际输出、错误原因；能解释后进入下一课。

## 独立练习与验收

1. 不看示例写出一次 batch 的五个步骤。
2. 打印一个参数在 backward 前后与 step 后的值，证明求导与更新不同。
3. 复制到自己的练习脚本，将 batch_size 改为 6，并把更新次数验收改为 400。

不以运行成功代替理解：至少独立完成全部任务，并解释每个关键操作。
