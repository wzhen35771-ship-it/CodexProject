# 主线结束后的研究准备

现有资料中的课题方向是“多路径自适应融合的静态场景图生成”。目前先完成 [学习计划](study_plan.md)，实际基线和模块接口以取得的源码为准。

## 进入研究实验前

- 选定一个基线和主数据集，记录仓库提交、权重、依赖和硬件。
- 检查数据划分、类别编号、过滤规则、主宾顺序与标注格式。
- 明确 PredCls/SGCls/SGDet、graph constraint、IoU 阈值、K、检测器和类别平均规则。
- 先跑官方权重或小样本流程，再考虑完整训练；学习练习不替代标准实验。

## 可逐项验证的研究问题

| 对照 | 要判断什么 |
|---|---|
| 基线与固定多路径 | 新增线索是否有帮助 |
| 同一路径集合下固定融合与自适应融合 | 门控本身是否有贡献 |
| 基线与增加图传播 | 上下文传播的独立作用 |
| 基线与增加 Logit Adjustment | 先验调整带来的取舍 |
| 最终模型分别移除门控、图传播、校正 | 各模块在组合中的作用 |

保持数据、评价、检测器与主要训练条件一致；预算允许时重复关键实验。报告 R/mR、逐类与头尾组表现、失败案例和开销，单次结果注明限制。

类别先验从训练集统计，参数在验证集选择；测试集用于最终报告。推理不能依赖只有训练标注提供的真实谓词或真实邻接。LA 的具体公式、位置和含义须核对源码。
