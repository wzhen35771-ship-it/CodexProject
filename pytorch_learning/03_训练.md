# 第三课：用梯度更新参数

今天只学一个核心：求导算出梯度，更新参数才会让模型的预测发生变化。

## 任务

给定输入 x=2，目标值是 6。模型只有一个参数 w，预测为 w×x。

| 名称 | 作用 | 本例 |
| --- | --- | --- |
| 输入 x | 交给模型的数据 | 2，固定 |
| 目标 target | 希望模型预测得到的答案 | 6，固定 |
| 参数 w | 训练时调整的数字 | 初始为 1，应该接近 3 |
| 预测 prediction | 模型按当前参数算出的结果 | 初始为 1×2=2 |
| 损失 loss | 衡量预测与目标的差距 | 初始为 (2−6)²=16 |
| 学习率 learning_rate | 每次更新的步长系数 | 0.1 |

这里只演示训练流程，一个样本并不足以说明模型在新数据上的表现。

## 一次更新

损失作为 w 的函数：L=(2w−6)²。

它对 w 的导数是：dL/dw=2×(2w−6)×2。最后乘 2 来自内层 2w 的导数，这就是链式法则。

当 w=1 时，梯度是 −16。

更新规则：新参数=旧参数−学习率×梯度。

因此，新参数=1−0.1×(−16)=2.6。

用新参数重新计算：预测=2.6×2=5.2；损失=(5.2−6)²=0.64。

| 状态 | 参数 w | 预测 | 损失 |
| --- | --- | --- | --- |
| 更新前 | 1 | 2 | 16 |
| 更新后 | 2.6 | 5.2 | 0.64 |

梯度下降指沿降低损失的方向更新。在这个例子中，梯度是负数，减去负数使参数增大。

## 对应代码

```python
import torch

x = torch.tensor(2.0)
target = torch.tensor(6.0)
w = torch.tensor(1.0, requires_grad=True)

prediction = w * x
loss = (prediction - target) ** 2
loss.backward()

with torch.no_grad():
    w -= 0.1 * w.grad

w.grad.zero_()
```

`torch.no_grad()` 让参数更新不被记录为新的求导运算，离开这个代码块后仍可继续对 w 求导。后续使用优化器时，它会帮我们完成更新。

`zero_()` 在原处清零梯度。本次更新用完梯度后再清零；下一轮就不会叠加上一次的梯度。

更新 w 后，原来的 prediction 和 loss 不会自动重算。必须再次执行预测与损失的计算，才能得到新结果。

## 反复训练

不断重复：预测 → 计算损失 → 求导 → 更新参数 → 清除梯度。
