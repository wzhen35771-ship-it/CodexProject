# 第五课：让模型学习一条直线

这一课把手动写出的 `w×x` 交给 PyTorch 的线性层，并让模型同时学习权重和偏置。

## 先看任务

我们给模型四组输入和目标，让它学会 `目标=3×输入+1`。

| 输入 | 目标 |
| --- | --- |
| −1 | −2 |
| 0 | 1 |
| 1 | 4 |
| 2 | 7 |

模型的预测规则是 `预测=权重×输入+偏置`。训练时输入和目标固定，模型调整权重与偏置。理想结果是权重接近 3，偏置接近 1。

| 概念或写法 | 中文含义 | 本课中的作用 |
| --- | --- | --- |
| `x` | 输入 | 四条样本，每条含一个数字 |
| `target` | 目标 | 每条输入对应的已知答案 |
| `nn.Linear(1, 1)` | 线性层 | 一个输入特征，输出一个预测值 |
| `model.weight` | 模型权重 | 输入乘以的系数，相当于上一课的 `w` |
| `model.bias` | 模型偏置 | 乘法结果之外再加的数 |
| `nn.MSELoss()` | 均方误差损失 | 将预测与目标之差平方，再对所有元素取平均 |
| `model.parameters()` | 模型参数 | 把权重与偏置交给优化器 |
| `torch.optim.SGD` | 随机梯度下降优化器 | 根据梯度更新参数；本例每次使用全部四条样本 |

## 为什么输入是两层方括号

```python
x = torch.tensor([[-1.0], [0.0], [1.0], [2.0]])
```

形状为 `[4, 1]`：4 表示四条样本，1 表示每条样本只有一个输入特征。`nn.Linear(1, 1)` 中两个 1 表示输入特征数和输出特征数，都不是样本数。

模型输出与目标的形状也都是 `[4, 1]`。把目标写成 `[-2., 1., 4., 7.]` 会得到 `[4]`，可能触发广播并计算出不符合本意的损失；本课保持预测和目标形状完全一致。

在本例中，权重形状为 `[1, 1]`，偏置形状为 `[1]`。先把它们理解成需要学习的两个数字即可。

## 训练循环

```python
optimizer.zero_grad()                      # 清除旧梯度
prediction = model(x)                      # 用当前参数预测
loss = loss_function(prediction, target)    # 衡量误差
loss.backward()                           # 计算梯度
optimizer.step()                          # 更新参数
```

这和第三课的过程一样，只是优化器替我们更新参数。`model(x)` 是一次预测，`optimizer.step()` 才会改变模型参数。

代码用 `torch.manual_seed(0)` 固定随机种子，学习率为 0.1，更新 100 次。种子便于重复比较初始参数和结果；不同运行环境仍可能有细小数值差异。

损失是在更新前算出来的，参数更新后，原来的预测和损失不会自动刷新。脚本末尾重新预测并计算最终损失。`torch.no_grad()` 表示这次只查看结果，不记录求导过程。
