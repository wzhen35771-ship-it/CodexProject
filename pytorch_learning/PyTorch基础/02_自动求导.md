# 第二课：自动求导

今天的目标：理解“计算结果”和“梯度”是不同的东西，并学会让 PyTorch 自动计算导数。

## 先认识导数

设 `y = x²`。当 x 变化时，y 也会变化。导数描述 y 在当前位置对 x 的变化有多敏感，也就是局部变化率。

这个函数的导数是 `2x`。当 x=2 时，y=4，而导数=4。两者这次恰好相同，并不意味着它们是同一个概念；当 x=3 时，y=9，而导数=6。

对于一个变量，梯度就是这个导数；对于多个变量，梯度包含各变量对应的偏导数。

## 今天的主例子

```python
import torch

x = torch.tensor(2.0, requires_grad=True)
y = x ** 2 + 3 * x
y.backward()

print(y.item())       # 计算结果：10
print(x.grad.item())  # 梯度：7
print(x.item())       # x 仍然是 2，求导没有更新它
```

手算过程：

- 计算结果：2² + 3×2 = 10。
- 导数：x² 的导数是 2x，3x 的导数是 3，所以总导数是 2x+3。
- 在 x=2 时，导数是 2×2+3=7。

## 四个代码写法

| 写法 | 中文含义 |
| --- | --- |
| `requires_grad=True` | 跟踪张量的运算，以便求导 |
| `backward()` | 进行反向传播，计算梯度 |
| `grad` | 保存计算得到的梯度 |
| `item()` | 将只有一个元素的张量转换成普通 Python 数值 |

在调用 `backward()` 之前，示例中 `x.grad` 是 `None`，表示梯度尚未计算。调用之后，梯度被存入 `x.grad`。
