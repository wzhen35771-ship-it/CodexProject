# 第九课：保存与加载模型参数

目标：训练结束后保存参数，重新建立模型并加载参数，验证预测保持一致。

## 保存的是什么

第五课学到的线性模型有权重和偏置。训练改变这些数字，保存参数就是把这些数字写入文件。

```python
torch.save(model.state_dict(), weight_path)
```

| 写法 | 中文含义 |
| --- | --- |
| `state_dict()` | 获取模型的参数与持久缓冲区字典 |
| `torch.save` | 将数据保存到文件 |
| `torch.load` | 从文件读取数据 |
| `load_state_dict` | 把参数装入已有模型 |
| `weights_only=True` | 使用适合读取参数字典的受限加载方式 |
| `map_location="cpu"` | 将读取的张量放到处理器上 |

本例的字典包含 `weight`（权重）和 `bias`（偏置）。文件后缀 `.pt` 是常见命名约定。

## 加载需要模型结构

```python
loaded_model = torch.nn.Linear(1, 1)
state = torch.load(weight_path, map_location="cpu", weights_only=True)
loaded_model.load_state_dict(state)
```

保存参数字典并不等于保存全部程序。加载时要建立与保存参数相匹配的模型结构。

## 评估和求导

```python
loaded_model.eval()
with torch.no_grad():
    prediction = loaded_model(test_x)
```

`eval()` 切换模型的运行模式；有些网络层在训练和评估时行为不同。`no_grad()` 则暂停记录求导过程。两者不是同一件事。

我们的简单线性层在两种模式下计算相同，但从现在开始养成预测时明确设置评估模式的习惯。
