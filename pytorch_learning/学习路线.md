# 学习路线

学习材料分为两个文件夹，按下面的入口查看。

| 学习部分 | 内容 | 学习入口 |
| --- | --- | --- |
| PyTorch 基础 | 第 01～09 课讲义、示例代码，以及自己的作业 | [PyTorch 基础学习路线](PyTorch基础/学习路线.md) |
| 视觉与数学基础 | 图片、物体框、矩阵、梯度、注意力与场景图 | [专题学习指南](视觉与数学基础/00_学习指南.md) · [第三步完整版](视觉与数学基础/第三步_完整版.md) |

## 文件放在哪里

- PyTorch 课程和作业放在 `PyTorch基础/`；已有 `01work.py`、`02work.py` 也在这里。
- 模型保存练习的输出放在 `PyTorch基础/outputs/`。
- 两部分共用外层 `.venv/` 的 Python 环境；依赖记录为外层 `requirements.txt`。

## 运行示例

运行 PyTorch 第三课：

```powershell
& 'E:\CodexProject\pytorch_learning\.venv\Scripts\python.exe' -X utf8 'E:\CodexProject\pytorch_learning\PyTorch基础\03_train.py'
```

运行其他练习时替换最后的脚本路径即可；各课程讲义中的运行命令已按新目录更新。
