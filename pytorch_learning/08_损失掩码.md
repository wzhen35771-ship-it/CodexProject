# 第八课：让部分标签的损失停止参与训练

你已学过每个输入元素都能有自己的梯度。本课直接观察：把一个标签的损失乘零，它对应的梯度会怎样变化。

## 先运行

在 PowerShell 使用同一个环境：

```powershell
& 'E:\CodexProject\pytorch_learning\.venv\Scripts\python.exe' -X utf8 'E:\CodexProject\pytorch_learning\08_masked_loss.py'
```

脚本使用三个独立的得分，不读取图像，不下载数据，也不训练完整网络。

## 和上一课的区别

上一课每个样本只选一个类别。本课把同一个物体对的三个关系标签分别判断为“成立”或“不成立”，因此目标可以是 `[1, 0, 1]`：第一个、第三个关系成立，第二个不成立。

这类监督叫多标签分类，一个物体对可以有多个成立的关系。这里用 `BCEWithLogitsLoss`：它接收原始得分和浮点型的零或一目标，内部包含概率转换和二元交叉熵计算。不要先手动调用 `sigmoid()` 再传入它。[官方说明](https://docs.pytorch.org/docs/stable/generated/torch.nn.BCEWithLogitsLoss.html)

## 概念表

| 代码名称 | 中文含义 | 本例 |
| --- | --- | --- |
| `logits` | 原始得分 | 三个独立得分，开始都是零 |
| `targets` | 目标标签 | `[1, 0, 1]` |
| `reduction="none"` | 暂不汇总 | 先得到三个逐项损失 |
| `mask` | 屏蔽掩码 | `[0, 1, 0]`，其中一表示屏蔽 |
| `keep = 1 - mask` | 保留标记 | `[1, 0, 1]`，其中一表示保留 |
| `effective_losses` | 有效逐项损失 | 逐项损失乘保留标记 |
| `clamp(min=1)` | 设置最小值 | 保证分母至少为一 |

掩码中零和一的含义是约定。本课 `mask` 的一是屏蔽，`keep` 的一是保留，两个变量不要混淆。

## 先算损失，再屏蔽，再平均

每个原始得分都为零，转换后的概率为 `0.5`，逐项损失约为：

```text
全部逐项损失：[0.6931, 0.6931, 0.6931]
保留标记：    [1,      0,      1]
有效逐项损失：[0.6931, 0,      0.6931]
```

只对两个保留标签取平均：

```text
有效平均损失=(0.6931+0.6931)÷2≈0.6931
```

这里不是除以三个标签的总数量。代码为：

```python
loss = (individual_losses * keep).sum() / keep.sum().clamp(min=1)
loss.backward()
```

先保留每一项，才能精确决定哪些项参与训练。如果全部被屏蔽，分子为零、分母被保护为一，损失和三个梯度都为零。实际训练还需决定这种批次要不要跳过。

## 梯度为什么是这些数

本例二元交叉熵对一个原始得分的导数为“预测概率−目标”：

```text
未平均、未屏蔽的梯度：[0.5−1, 0.5−0, 0.5−1]=[-0.5, 0.5, -0.5]
屏蔽第二项，再除以保留数量2：[-0.25, 0, -0.25]
```

`loss.backward()` 会把最终梯度保存到 `logits.grad`。第一个、第三个梯度为负；如果随后执行梯度下降更新，它们的得分会增大，让成立关系的预测概率靠近一。

本例还没执行参数更新，只观察一次梯度。原始得分在求导后仍然为零。求导和更新的区别可回看[自动求导官方教程](https://docs.pytorch.org/tutorials/beginner/basics/autogradqs_tutorial.html)。

## 怎样连接到 ImparTail

一个图像或视频可以包含多个关系标签。屏蔽其中一个标签的损失，并没有删掉图像，也没有删掉其他标签。它只是取消这一项在本次训练中的监督作用。

本例三个得分相互独立，第二个梯度因此为零。真实网络的特征和参数通常被多个关系共享：其他保留关系仍能更新共享参数，所以被屏蔽关系的预测在后续也可能变化。

本课只演示“按标签屏蔽损失”的基础思想。论文还包含具体标签选择、掩码比例、训练策略、数据和评估设置；学会这个例子后再对照其完整实现。
