# 文件与代码命名规范

## 当前目录

- `00_学习总览.md`：学习入口。
- `01_命名规范.md`：本文件。
- `02_静态场景图学习方案.md`：当前路线与验收。
- `03_当前学习周报.md`：可编辑周报。
- `PyTorch基础/`：当前基础讲义、示例及个人作业。
- `requirements.txt`：基础示例依赖；研究仓库另设环境。

## 课程与作业

按“两位序号_中文主题_类型”命名。同一课的讲义与示例使用相同序号和主题。

| 类型 | 示例 |
| --- | --- |
| 讲义 | `01_张量_讲义.md` |
| 示例 | `01_张量_示例.py` |
| 个人作业 | `01_张量_作业.py` |
| 教学权重 | `03_训练循环_权重.pt`，运行时存入专题的 `outputs/` |

每个专题使用一个 `00_学习指南.md`。按当前需要补课程，避免重复合订和重复入口。

## 代码名称

函数、变量和属性用英文 `snake_case`，类用 `PascalCase`，常量用大写英文。注释、解释和输出提示使用中文。保留 `forward`、`__init__` 等框架名称及官方仓库原文件名。

## 提交标题

使用“学习：具体动作与对象”，例如“学习：重写静态场景图基础课程”。标题描述本次实际变化。
