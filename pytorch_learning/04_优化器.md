# 第四课：优化器

目标：独立写出清除梯度、求导、更新参数三步，并解释它们各自的职责。

## 从上一课接过来

上一课手动执行：

```python
with torch.no_grad():
    w -= 0.1 * w.grad
```

现在让优化器完成同一件事：

```python
optimizer = torch.optim.SGD([w], lr=0.1)
optimizer.step()
```

这里采用默认的 SGD 设置，没有动量或权重衰减，更新规则仍然是：新参数=旧参数−学习率×梯度。

## 读懂创建优化器的这一行

| 写法 | 含义 |
| --- | --- |
| `optimizer` | 保存优化器的变量名 |
| `torch.optim` | PyTorch 的优化器模块 |
| `SGD` | 随机梯度下降优化器 |
| `[w]` | 告诉优化器需要更新哪些参数，这里只有 w |
| `lr=0.1` | 学习率为 0.1 |

创建优化器不会立刻更新参数。它也不会自己计算梯度。

## 三步分工

| 代码 | 作用 | 是否更新参数 |
| --- | --- | --- |
| `optimizer.zero_grad()` | 清除上一轮梯度 | 否 |
| `loss.backward()` | 计算本轮损失对参数的梯度 | 否 |
| `optimizer.step()` | 根据已有梯度更新参数 | 是 |

`zero_grad()` 默认可能把梯度设置为 `None`，不一定是数值零。它的目的是避免旧梯度参与新一轮计算。

上一课在一次更新结束后清零，这一课在下一次求导前清除；两种安排都能避免意外累加。

## 最小训练循环

```python
import torch

x = torch.tensor(2.0)
target = torch.tensor(6.0)
w = torch.tensor(1.0, requires_grad=True)
optimizer = torch.optim.SGD([w], lr=0.1)

for step in range(5):
    optimizer.zero_grad()
    prediction = w * x
    loss = (prediction - target) ** 2
    loss.backward()
    optimizer.step()
```

预期第一次参数从 1 变为 2.6；第二次变为 2.92；五次更新后约为 2.99936。

注意：更新参数后，旧的 `prediction` 和 `loss` 不会自动重算。配套脚本明确区分更新前的数据和更新后的参数。
