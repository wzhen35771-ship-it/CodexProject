# 原学习路线第三步：视觉与数学基础

这套教材对应你最初学习路线中的第三步“视觉与数学基础”。它与 PyTorch 练习中的第三课 `03_手动训练_示例.py` 是两个不同的编号体系。

目标是让你能解释：图片怎样进入模型，物体和关系怎样表示，矩阵运算怎样得到预测，梯度怎样改变参数，以及这些知识怎样接到 ImparTail。

## 一、你学完以后应当能做什么

1. 已知按 NCHW 排列时，看到 `[2, 3, 100, 200]`，能说明两张图片、三个通道、高一百、宽两百。
2. 能区分图片坐标 `(x, y)` 与张量索引 `[行, 列]`。
3. 能从四个框坐标算出宽、高、中心和两个框的交并比。
4. 能解释物体类别、物体特征、关系得分分别是什么。
5. 能手算一次向量点积和一个小矩阵乘法，并预测结果形状。
6. 能从损失表达式手算参数梯度，说明反向传播与参数更新的区别。
7. 能区分分类得分、概率和标签，理解为什么不同任务使用不同损失。
8. 能读懂一次单头注意力计算的形状及加权求和过程。
9. 能将“人拿着杯子”写成关系三元组，并说明视频中的关系如何变化。
10. 能解释损失掩码屏蔽了什么，以及它为什么可能改善长尾类别的学习。

## 三、先分清训练中的六种东西

| 名称 | 谁提供它 | 在训练中起什么作用 | 一个例子 |
| --- | --- | --- | --- |
| 输入数据 | 数据集 | 交给模型处理 | 一张图片、一个视频片段 |
| 标注或目标 | 人工标注或任务定义 | 告诉训练程序期望的答案 | 物体框、类别、“拿着”关系 |
| 参数 | 模型初始化，随后被训练调整 | 控制模型如何计算 | 线性层权重与偏置 |
| 预测 | 模型按当前参数算出 | 给出当前答案或得分 | 预测框、类别得分 |
| 损失 | 比较预测与目标 | 衡量当前预测与监督的差距 | 平方误差、交叉熵 |
| 梯度 | 对损失求导 | 描述损失对各参数的局部变化率 | `model.weight.grad` |

输入、标注和参数要分别看。模型输出类别，并不会自动产生正确的训练标注；求导得到梯度，也不会自动更新参数。

## 四、贯穿全套的例子

考虑一段视频：一个人先看杯子，然后拿起杯子，最后喝水。

```text
视频帧的像素
    ↓
检测物体：人、杯子；估计它们的位置
    ↓
为物体和物体对计算特征
    ↓
结合同帧和跨帧的信息
    ↓
输出关系得分
    ↓
形成三元组：人—看着—杯子、人—拿着—杯子等
```

训练时，还要把预测与已知标注比较，计算损失，再求导和更新模型参数。ImparTail 关注关系监督的分布：常见关系出现很多次，少见关系出现很少；它通过掩码策略改变哪些关系损失在本次训练中参与学习。

这张流程图帮助理解常见的物体中心视频场景图方法；具体模型会有不同的检测、特征处理和关系模块。

## 五、怎样读公式

看到公式时，按四步读：

1. **找输入与输出。** 例如 `Y=XW+b`，输出是 Y。
2. **标形状。** 例如 X 为 `[样本数, 输入特征数]`。
3. **判断操作。** 这里有矩阵乘法和偏置相加。
4. **代入小数字。** 先用一两条样本算一次，再理解大的张量。

看到导数时额外问一句：“对谁求导？”`dL/dw` 表示损失 L 对参数 w 的导数，不是对损失再平方，也不是对上一次保存的梯度求导。

## 六、怎样读代码

先给变量写上中文解释，然后记录形状，再找出三类语句：

```python
prediction = model(inputs)     # 用当前参数计算预测
loss = criterion(prediction, targets)  # 根据预测和标注计算损失
loss.backward()               # 计算梯度
optimizer.step()              # 使用梯度更新参数
```

注意当前变量代表的是更新前还是更新后的结果。参数更新后，旧预测不会自行重算。

遇到张量维度操作，用“旧顺序→新顺序”写出来，例如 `[高,宽,通道]→[通道,高,宽]`，比直接背 `permute(2,0,1)` 更容易迁移到新任务。

## 八、学习与检查方法

每次学一个单元：先手算，运行核对，改一个数，再独立解释一次。讲义中的“参考答案”默认折叠，先做题再展开。

可以把全套内容分成下面九次学习。次数只是安排方式，是否进入下一次，以你能独立完成右栏的任务为准。

| 次序 | 重点 | 结束前独立完成 |
| --- | --- | --- |
| 第一次 | 像素、RGB、图片张量 | 写出两行两列彩色图片，取出指定像素 |
| 第二次 | 维度顺序、坐标、预处理 | 完成 HWC → CHW → NCHW，并解释浮点转换与缩放 |
| 第三次 | 物体框、交并比、视觉特征 | 手算宽高、中心、IoU；区分类别与特征 |
| 第四次 | 向量、矩阵、线性层 | 手算矩阵乘法，写出线性层输入、权重和输出形状 |
| 第五次 | 导数、链式法则、参数更新 | 不看答案推导 `2(wx-t)x`，算出一次更新 |
| 第六次 | 概率、单类别与多标签损失 | 解释原始得分与概率，选对标签格式和损失输入 |
| 第七次 | 注意力 | 手算得分、缩放、权重与融合输出 |
| 第八次 | 场景图、时序、评估、掩码 | 解释节点、边、任务设置、R/mR 和损失掩码 |
| 第九次 | 综合程序与独立作业 | 自己写两个物体对的训练示例，并说明每一步形状 |

当你能独立写出并解释综合练习的主要数据形状、损失与参数更新过程时，就可以继续读 STTran 的特征处理流程，再对照 ImparTail 的掩码实现。

其中物体检测器的完整训练、复杂卷积网络、多头注意力的工程实现是后续扩展；本专题把它们的接口、核心直觉和必要数学先讲清楚。
