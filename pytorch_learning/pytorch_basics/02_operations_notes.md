# 第 2 课：运算、求和与广播

## 本课概念

`+`、`-`、`*` 对对应元素操作；`@` 表示矩阵乘法。
`[2, 3] @ [3, 2]` 得到 `[2, 2]`，内侧大小必须相等。
`sum(dim=0)` 沿行轴求和，得到每列的总和；`sum(dim=1)` 沿列轴求和，得到每行的总和。
默认求和消去指定轴，`keepdim=True` 保留该轴且大小为 1。
广播从末尾对齐各轴：大小相同或其中一个为 1 才能兼容。`[2, 3] + [3]` 给每一行加同一个向量。

## 怎么学

1. 先读概念，用纸笔预测示例输出。
2. 运行 [02_operations_example.py](02_operations_example.py)，逐行对照预测。
3. 关闭示例，完成 [02_operations_exercise.py](02_operations_exercise.py)。
4. 写下形状、实际输出、错误原因；能解释后进入下一课。

## 独立练习与验收

1. 手算示例的两种求和结果及形状。
2. 创建 [3, 4] 与 [4, 2] 张量，做矩阵乘法并解释输出形状。
3. 尝试 [2, 3] + [2]，记录报错原因，再把偏移量改成 [2, 1]。

不以运行成功代替理解：至少独立完成全部任务，并解释每个关键操作。
