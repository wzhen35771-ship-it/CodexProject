# 第 1 课：认识张量

## 本课概念

张量是带有形状的数字容器。标量没有轴，一维张量有一个轴，二维张量有两个轴。
`shape` 给出各轴大小，`ndim` 是轴的数量，`numel()` 是元素总数。
`[2, 3]` 表示两行三列：2 个维度、6 个元素。不要把维度数量和元素数量混为一谈。
`dtype` 表示元素类型；小数通常使用 float32，类别编号通常使用 long。`device` 表示数据所在设备，本课程先使用 CPU。
索引从 0 开始：`x[1]` 是第二行，`x[:, -1]` 是所有行的最后一列。冒号表示保留这一轴的所有位置。

## 怎么学

1. 先读概念，用纸笔预测示例输出。
2. 运行 [01_tensors_example.py](01_tensors_example.py)，逐行对照预测。
3. 关闭示例，完成 [01_tensors_exercise.py](01_tensors_exercise.py)。
4. 写下形状、实际输出、错误原因；能解释后进入下一课。

## 独立练习与验收

1. 创建三行两列的张量，数字依次为 1 到 6。
2. 打印 shape、ndim、numel、dtype、device，并用中文说明含义。
3. 取第二行、第一列和第三行第二列；先预测再运行。

不以运行成功代替理解：至少独立完成全部任务，并解释每个关键操作。
