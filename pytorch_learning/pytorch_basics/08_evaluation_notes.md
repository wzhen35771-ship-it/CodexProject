# 第 8 课：评估、保存加载与综合验收

## 本课概念

`eval()` 切换 Dropout、BatchNorm 等层的行为，不自动关闭梯度。`no_grad()` 关闭梯度记录，不切换层模式。
训练集用来更新参数，验证集用于选择设置，测试集用于最后评价；不要根据测试结果反复调参。
本课使用另行手工指定的 6 条人工样本作教学评估，不参与训练。这么小的人工集不足以证明真实泛化。
`state_dict` 保存模型参数；加载时创建同结构模型，再 load_state_dict。保存参数不等于保存完整续训状态。
加载刚由自己生成的权重，使用 map_location='cpu' 和 weights_only=True。核对保存前后 logits，而非只比较类别。
综合验收：从零写模型、数据批次、训练和评估，并解释每一步形状。完成后再进入图像特征、检测与静态场景图。

## 怎么学

1. 先读概念，用纸笔预测示例输出。
2. 运行 [08_evaluation_example.py](08_evaluation_example.py)，逐行对照预测。
3. 关闭示例，完成 [08_evaluation_exercise.py](08_evaluation_exercise.py)。
4. 写下形状、实际输出、错误原因；能解释后进入下一课。

## 独立练习与验收

1. 解释 eval 与 no_grad 的区别。
2. 尝试加载到隐藏层宽度不同的模型，记录错误并修复。
3. 独立完成分类程序，记录训练与评估结果，以及为何这些结果不能代表真实场景图效果。

不以运行成功代替理解：至少独立完成全部任务，并解释每个关键操作。
