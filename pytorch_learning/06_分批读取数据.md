# 第六课：把数据分批读取

第五课一次将四条样本全部交给模型。数据多时，可以每次只读一小批。这一课先只读取和打印，不训练模型。

## 两个工具分别负责什么

| 写法或概念 | 中文含义 | 本课中的作用 |
| --- | --- | --- |
| 样本 | 一条完整数据 | 一条输入及其对应目标 |
| `TensorDataset` | 张量数据集 | 根据行号将输入和目标配对 |
| `DataLoader` | 数据加载器 | 按指定批次大小读取数据集 |
| `batch_size` | 批次大小 | 一批包含多少条样本 |
| `shuffle` | 是否打乱样本顺序 | `False` 表示按原始顺序读取 |
| `len(dataset)` | 样本总数 | 本例为 4 |
| `len(loader)` | 一轮的批次数 | 本例为 2 |
| `tolist()` | 转为普通列表 | 方便查看整批数值，不限于一个元素 |

数据仍然来自上一课：

```python
x = torch.tensor([[-1.0], [0.0], [1.0], [2.0]])
target = torch.tensor([[-2.0], [1.0], [4.0], [7.0]])
dataset = TensorDataset(x, target)
loader = DataLoader(dataset, batch_size=2, shuffle=False)
```

输入和目标的形状都是 `[4, 1]`。两者第一维长度必须一致，才能按行配对。输入 −1 配目标 −2，输入 0 配目标 1，以此类推。

```python
for batch_x, batch_target in loader:
    print(batch_x.tolist(), batch_target.tolist())
```

循环每次取出一批输入及对应目标。这里不必自己计算下一批从哪一行开始。

## 轮次、批次和迭代次数

| 概念 | 表示什么 | 四条样本、批次大小为 2 时 |
| --- | --- | --- |
| 一轮（`epoch`） | 将整份训练数据遍历一次 | 读完两批是一轮 |
| 一批（`batch`） | 一起读取的一组样本 | 每批两条样本 |
| 一次迭代（`iteration`） | 执行一次循环体 | 本例读取一批；训练时通常对这一批更新一次参数 |

因此，本例一轮有两次迭代。如果训练 3 轮，而且每批更新一次参数，总共有 6 次参数更新。**本课脚本只读取数据，没有参数更新。**

`batch_size=3` 时，前一批有 3 条样本，后一批剩 1 条。默认 `drop_last=False`，不足一批的样本也会被读取。批次大小是每批最多包含多少条，不保证最后一批也满额。

`shuffle=True` 会打乱样本的读取顺序，输入与目标仍成对出现，整份数据仍会被遍历。它不会把输入和目标各自随意打乱。

  目标数值：[[-2.0], [1.0]]

目标形状也都是 `[2, 1]`。整份数据形状 `[4, 1]` 中的 4，在每个批次里变成当前批次的样本数；每条样本仍然只有一个特征。

## 练习与自检

新建 `06work.py`，复制示例后每次只改一个设置。先预测结果，再运行核对。

1. 改成 `batch_size=1`：应有 4 批，每批输入和目标的形状都是 `[1, 1]`。
2. 改成 `batch_size=3`：应有 2 批，形状分别是 `[3, 1]` 和 `[1, 1]`。解释为什么不需要把剩余样本删掉。
3. 改成 `shuffle=True`：观察顺序，检查每条输入对应的目标仍符合 `3×输入+1`。一次随机打乱也有可能恰好保持原顺序。
4. 手算：4 条样本、批次大小为 3，训练 5 轮且每批更新一次，总共有多少次更新？答案是 10 次。

本课固定了随机种子，便于重复运行比较。下一步再把数据加载器接到训练循环中。
