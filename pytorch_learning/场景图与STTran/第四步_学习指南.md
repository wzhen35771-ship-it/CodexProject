## 二、始终抓住这一条主线

```text
视频帧
   ↓
检测器/区域特征提取器
   ↓
物体框、物体类别信息、物体视觉特征
   ↓
构造人—物体对的关系表示
   ↓
空间模块：同一帧的关系上下文
   ↓
时间模块：相邻帧窗口的关系上下文
   ↓
三组关系预测
   ├─ 训练：标注 → 损失 → 求导 → 更新参数
   └─ 评估：候选 → 构图 → 排序 → 匹配 → 召回
```

遇到新词时，先找它在这条路径的哪个位置，再查它的输入、输出和形状。

## 三、怎么读每一章

1. 先读目标与小例子，写出你预测的结果。
2. 给公式的变量写中文含义，给张量写形状。
3. 手算两三个数字，再运行配套代码核对。
4. 只改一个数字或设置，预测变化，再验证。
5. 先完成练习，再展开折叠参考答案。
6. 用自己的话解释一条完整计算路径，再进入下一章。

公式较多的第三、四天可以拆成多次阅读。参考答案与代码用来核对，不必把固定随机参数产生的每个数字都背下来。

## 五、官方实现与教学演示怎样对应

| 内容 | 本教材处理方式 |
| --- | --- |
| 官方STTran的数据路径与结构 | 对照作者论文和代码说明，标明实际接口与形状 |
| 关系特征演示 | 用人工区域特征、小维度投影与布局，手算索引和组合 |
| 空间时间演示 | 用D=8的模块，演示真实层顺序、有效行、位置向量与窗口还原 |
| 关系训练演示 | 用小分类器，保留3/6/17三个分组及对应损失格式 |
| 评估演示 | 用人工候选、小K和连续坐标IoU，观察排序与匹配 |
| 完整数据集与原版训练环境 | 后续复现阶段准备；本阶段先掌握计算和协议 |

各章节明确写出教学简化的位置。运行小练习能验证数学和接口，不表示已经完成原论文的精度复现。

## 六、阶段完成的标准

不看教材，能完成：

- 写出场景图、实例编号和跨帧物体对索引。
- 解释五部分关系表示以及1936的来源。
- 手算点积注意力、LayerNorm、正负类别间隔损失。
- 追踪同帧填充、相邻窗口与还原顺序。
- 说明三组标签、损失输入、梯度如何传到参数。
- 说明构图、方向、排序、框匹配与R@K。
- 沿官方代码找到关系前向、时序组织、损失和评估的位置。

完成后继续阅读 ImparTail：关注它沿用的基线，以及关系监督、掩码生成和损失归一化怎样变化。
