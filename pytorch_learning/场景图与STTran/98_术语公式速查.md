# 第四步术语、形状与公式速查

详细解释与手算在五个章节中。这份表用于阅读时找回变量含义；先理解例子，再记公式。

## 1. 本教材使用的数量符号

| 符号 | 含义 |
| --- | --- |
| T | 当前视频条目中的帧数 |
| N | 所有帧合计的物体框数量 |
| M | 所有帧合计的人—物体对数量 |
| L | 单帧最多的物体对数量 |
| D | 关系特征维数，官方此处为1936 |
| h | 注意力头数，官方此处为8 |
| d_k | 单个头的查询/键维数，此处1936÷8=242 |
| C | 当前分类分支的类别数 |
| K | 召回指标中保留的前K个预测 |

论文中的字母可能有其他定义，例如某段用N表示网络层数。看公式时优先看该段定义，而不是固定认为某个字母永远是物体数。

第三、四天讲义也用R表示关系特征或关系样本的行数，对应这里的M；第三天用H表示注意力头数，对应这里的h。

## 2. 术语

| 英文或代码名称 | 中文 | 用途 |
| --- | --- | --- |
| node / edge | 节点 / 边 | 物体实例 / 物体间关系 |
| predicate / triplet | 谓词关系 / 三元组 | 关系类别 / 关系两端及其标签 |
| object instance | 物体实例 | 当前画面中具体的某个物体 |
| bounding box | 边界框 | 表示位置范围 |
| proposal / RoI | 候选区域 / 感兴趣区域 | 检测器提出或后续提取特征的区域 |
| RoIAlign | 区域特征对齐 | 从特征图按区域得到固定大小的表示 |
| union box | 联合框 | 覆盖两个物体框的矩形 |
| spatial mask | 空间布局图 | 表示两个框在共同区域的位置 |
| embedding | 嵌入向量 | 按类别或位置索引查出的学习表示 |
| concatenate / flatten | 拼接 / 展平 | 合并维度 / 将多个维度展开 |
| relation representation | 关系表示 | 一个物体对用于预测关系的特征 |
| spatial encoder | 空间编码器 | 融合同一帧的关系信息 |
| temporal decoder | 时间解码器 | 融合邻接帧窗口中的关系信息 |
| padding / mask | 填充 / 掩码 | 组织不同长度输入 / 屏蔽对应位置 |
| residual / LayerNorm | 残差连接 / 层归一化 | 相加原表示 / 调整最后特征维的尺度 |
| FFN | 前馈网络 | 对每个关系表示应用同一组线性与非线性计算 |
| logits | 原始分类得分 | 作为相应分类损失的输入 |
| multi-label | 多标签 | 同一样本可以对应多个正类别 |
| margin loss | 间隔损失 | 使正类别得分相对负类别更高 |
| ground truth / prediction | 真值 / 预测 | 监督答案 / 当前模型结果 |
| recall | 召回率 | 真值中找回了多少 |
| constraint | 构图约束 | 控制保留哪些候选关系 |

空间布局图、注意力填充掩码、ImparTail损失掩码作用位置不同，即使都包含0/1，也必须按具体约定读。

## 4. 关键公式

### 图和索引

\[
G_t=(V_t,E_t)
\]

节点是具体物体，边是关系。关系表示每行对应一个物体对。

### 线性层

\[
Y=XW^T+b
\]

按PyTorch保存约定，W形状为`[输出维,输入维]`。

### 关系特征

\[
r=[v_s'\,;\,v_o'\,;\,v_u'\,;\,e_s\,;\,e_o]
\]

分号表示拼接。长度为`512+512+512+200+200=1936`；联合区域与框布局先作相应处理和逐元素相加，再展平投影。

### 单头注意力

\[
A=\mathrm{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right),\qquad O=AV
\]

softmax沿每个查询的键候选方向。填充key在权重计算时被排除。

### 层归一化

对一个D维表示：

\[
\mu=\frac1D\sum_jx_j,\qquad
\sigma^2=\frac1D\sum_j(x_j-\mu)^2
\]

\[
\mathrm{LN}(x)_j=\gamma_j\frac{x_j-\mu}{\sqrt{\sigma^2+\epsilon}}+\beta_j
\]

这里使用总体方差；gamma、beta是可学习参数。它不是将所有帧或所有关系混在一起算一个均值。

### 前馈网络

\[
\mathrm{FFN}(X)=\mathrm{ReLU}(XW_1^T+b_1)W_2^T+b_2
\]

官方维度`1936→2048→1936`。同一组参数应用于各个关系表示。

### 单标签交叉熵

\[
p_j=\frac{\exp(s_j)}{\sum_k\exp(s_k)},\qquad L=-\ln p_c
\]

c为真实类别；常用CrossEntropyLoss接收原始分数。

### 二元交叉熵

\[
p=\mathrm{sigmoid}(s),\qquad
L=-y\ln p-(1-y)\ln(1-p)
\]

BCELoss接收概率；BCEWithLogitsLoss接收原始分数。官方STTran的BCE分支使用前者，因为对应输出已做sigmoid。

### 多标签间隔损失

无类别加权时，一个C类样本可写为：

\[
L=\frac1C\sum_{p\in P^+}\sum_{q\notin P^+}\max(0,1-s_p+s_q)
\]

PyTorch默认reduction会再对样本取平均。目标是正类别索引列表、long类型、−1填充；与BCE多热目标不同。

### 最简单的参数更新

\[
\theta_{\mathrm{新}}=\theta_{\mathrm{旧}}-\eta\nabla_\theta L
\]

这是普通梯度下降的表达；AdamW等优化器还有自身的状态和更新规则。

### 三元组得分与召回

\[
s_{\mathrm{三元组}}=s_{\mathrm{主体}}s_{\mathrm{关系}}s_{\mathrm{客体}}
\]

\[
R@K=\frac{\text{匹配到的不同真实关系数}}{\text{该帧真实关系数}}
\]

先构图、排序、按协议匹配，之后计算召回；对应官方评估再聚合各帧结果。
